# Experimental Protocol

## Phase E0 — Environment

- Create isolated Python environment.
- Install pinned dependencies.
- Record hardware and software versions.
- Verify deterministic seed behavior as far as supported by the hardware stack.

## Phase E1 — Dataset

- Acquire a legally usable public biomedical segmentation dataset.
- Record source, version, access date and license/terms.
- Inspect class balance and image/mask dimensions.
- Validate that every image has the expected mask.
- Define train/validation/test splits before model training.
- Prevent patient-level or subject-level leakage where applicable.

## Phase E2 — U-Net Baseline

- Implement the architecture independently.
- Run shape/unit tests.
- Train using the predefined configuration.
- Save configuration, checkpoints, training history and test metrics.

## Phase E3 — Attention U-Net

- Implement attention gates from the published architectural description.
- Verify tensor dimensions and gate placement.
- Train with the same controlled protocol.
- Save all artifacts and metrics.

## Phase E4 — Ablation

Compare the complete Attention U-Net with an equivalent configuration where attention gates are removed. Keep all other factors constant.

## Phase E5 — Efficiency

Measure parameters, inference latency and other feasible computational indicators. Perform repeated timing after warm-up and report the measurement protocol.

## Phase E6 — Error Analysis

Analyze false-positive and false-negative regions, boundary quality and difficult examples. Do not only show best cases.

## Phase E7 — Reproduction Analysis

Compare the direction and magnitude of findings with the original paper. Clearly distinguish exact reproduction from conceptual or partial reproduction when datasets, preprocessing, hardware or training procedures differ.

## Result Integrity Rule

No number is entered into the final results table unless it is generated by the experiment code and traceable to a saved run.
