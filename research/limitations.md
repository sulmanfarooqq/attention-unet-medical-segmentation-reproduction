# Limitations

1. A reproduction using a different dataset cannot be treated as an exact replication of the original study.
2. Differences in preprocessing, augmentation, optimization, hardware and software versions can affect performance.
3. Medical-image segmentation metrics can hide clinically meaningful boundary errors.
4. A limited number of random seeds may underestimate variance.
5. Inference latency depends strongly on hardware and measurement methodology.
6. Public datasets may not represent the full diversity of clinical populations.
7. This project is not a clinical validation study.
8. Reported improvements should not be interpreted as evidence of clinical benefit.
9. Any dataset-specific restrictions must be respected; raw medical data should not be committed to the repository unless redistribution is explicitly permitted.
