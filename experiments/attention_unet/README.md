# E3 — Attention U-Net

## Goal
Measure the effect of attention gates under conditions matched to the baseline experiment.

## Required artifacts

- Configuration
- Training history
- Checkpoint identifier
- Test metrics
- Parameter count
- Inference timing
- Environment metadata

## Comparison rule
Do not select a different training budget, dataset split or preprocessing pipeline solely because it produces a better result. Any intentional change becomes a separately documented experiment.
